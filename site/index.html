Every piece of that path is declared in Terraform. State is stored remotely in a separate S3 bucket with lockfile locking, and the code is public: aws-terraform-static-site.

Design decisions

The bucket is private
All public access is blocked. The bucket policy lets exactly one CloudFront distribution read objects, so there is no way to reach the content except over HTTPS through the edge.
State lives in S3, not on a laptop
Remote state means the infrastructure can be managed from any machine, and S3's native lockfile stops two applies from running at once.
State never touches the repository
State and variable files are gitignored, and the state bucket is separate from the bucket that serves this page.
Next: keyless deploys
A GitHub Actions pipeline that assumes an AWS role through OIDC, so no long-lived access keys exist anywhere.
